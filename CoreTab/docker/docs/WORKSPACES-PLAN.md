# 三工作台第一阶段实施方案

## 目标与边界

依据 coreTab.md V2.0 需求和三工作台视觉稿，先交付统一导航与两个可交互的新工作台。不重排、不重写现有 Tabs（Quick Action、Navigation、Closed Tabs、Recent Tabs、Open Tabs、GitHub Trending、History）。

- 技术：沿用原生 JavaScript、经典脚本、CSS，无新运行时依赖。
- 视觉：复用 style.css 的 cream / matcha / oat / swatch token；新页面还原稿件的信息层级、侧栏、双列卡片、双栏会议区和底部提示。
- 导航：使用 #tabs / #prompts / #meetings，支持直达、浏览器前进后退；面板隐藏而不销毁，保留筛选、草稿和滚动位置。
- 搜索：Tabs 保持原搜索；新工作台独立搜索，不声称已实现跨工作台统一搜索。

## 模块拆分

1. coretab-workspaces.js：导航、共享图标、本地存储、弹窗、剪贴板操作。
2. coretab-prompts.js：Prompt Library、分类计数、收藏、搜索、模型/标签筛选、排序、分页、编辑器与变量预览。
3. coretab-meetings.js：会议空态、独立示例、创建、计时/暂停/结束、手动记录、摘要/行动项编辑、历史记录。
4. styles/workspaces.css：仅作用于新工作台与全局 Header，不修改旧 style.css。

## 本次功能

### Prompts

首次提供六个可编辑模板；新建、编辑、软删除/回收站恢复、收藏、复制计数、本地持久化。变量支持 {{name}}，右栏填写变量后实时预览。模型名称仅作为元数据，不运行模型测试。

### Meetings

默认展示空态；通过“查看示例”展示视觉稿中的转写、摘要和行动项。示例不混入用户历史、不自动录音。新建会议为本地手动记录模式，可暂停/继续、添加带时间戳和说话人的记录、维护摘要/结论/行动项、结束归档、查询和重开历史详情。进行中数据随操作保存，刷新后暂停恢复，避免把离开页面的时长误当录音时长。

**不接入麦克风、语音识别、说话人自动分离或 AI 服务；不上传音频；不展示伪造的真实 LIVE 状态。** 真实录音、ASR、模型鉴权、断线恢复与自动摘要留待下一阶段确定服务方案。

## 数据与隔离

新数据使用独立的 coretab_prompts_v1 / coretab_meetings_v1 本地存储键，不接触旧 Tabs 数据；保存失败明确提示且不假报成功。示例会议仅驻留内存。无新增扩展权限或外部服务。

## 验收

- 原 84 项测试保持通过；旧 Tabs 脚本、样式、权限不变。
- 浏览器验证导航/前进后退、DOM 状态保留、Prompt CRUD/变量/筛选/持久化、会议暂停/结束/历史和示例隔离。
- 校验存储失败、输入转义、空态、键盘弹窗、桌面与窄屏无横向溢出。
- 启动静态服务供预览；预览不具备 Chrome 扩展 API，Tabs 真实操作需加载扩展验证。
