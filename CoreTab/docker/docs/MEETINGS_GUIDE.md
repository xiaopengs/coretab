# 会议转写工作台使用指南

> CoreTab Meetings - 让每一次会议都有价值

---

## 功能概述

会议转写工作台是 CoreTab 的三大工作台之一，提供实时的会议录音、语音转文字、智能整理和导出功能。

### 核心能力

- **实时录音**：基于 Web Speech API 的语音识别
- **语音转文字**：支持中英文混合识别，自动添加时间戳
- **智能整理**：自动提取摘要、关键结论和行动项
- **导出分享**：支持 TXT 和 Markdown 格式导出
- **历史记录**：所有会议记录本地保存，随时查阅

## 快速开始

### 1. 创建会议

1. 点击顶部导航栏的「Meetings」切换到会议工作台
2. 点击「新建会议」按钮
3. 输入会议名称（如"产品评审会"、"周会"等）
4. 点击「开始会议」

### 2. 会议进行中

会议开始后，你会看到：

```
┌─────────────────────────────────────────┐
│  正在录音  产品评审会  0:15:32           │
│  [暂停] [结束会议]                       │
├─────────────────────────────────────────┤
│  实时转写              │  AI 会议助手    │
│  ───────────────────── │  ────────────   │
│  Speaker: 今天我们要... │  实时摘要       │
│  [0:00:15] 我们决定...  │  • 决定了...    │
│                        │                │
│  + 添加转写             │  关键结论       │
│  [说话人] [输入内容]    │  • 结论1...     │
│                        │                │
│                        │  Action Items   │

└─────────────────────────────────────────┘
```

#### 语音识别模式

如果浏览器支持 Web Speech API（Chrome/Edge），系统会自动启动麦克风进行语音识别：

- 状态显示「正在录音」
- 语音会自动转为文字并添加到转写列表
- 每条记录自动添加时间戳和说话人

#### 手动输入模式

如果浏览器不支持语音识别，或你更喜欢手动记录：

- 状态显示「手动模式」
- 在「说话人」输入框填写发言人姓名
- 在「输入内容」框输入转写内容
- 点击「添加」或按 Enter 键添加记录

### 3. 会议整理

在右侧「AI 会议助手」面板中：

**添加摘要**
- 在「实时摘要」输入框输入摘要内容
- 点击「+」按钮或按 Enter 添加

**添加关键结论**
- 在「关键结论」输入框输入结论
- 点击「+」按钮或按 Enter 添加

**添加行动项**
- 在「Action Items」输入框输入待办事项
- 点击「+」按钮或按 Enter 添加
- 可以勾选 checkbox 标记完成状态

### 4. 暂停/继续会议

如果需要暂停会议（如休息、茶歇）：

1. 点击「暂停」按钮
2. 状态变为「已暂停」，计时器停止
3. 语音识别也会暂停
4. 点击「继续」恢复会议

### 5. 结束会议

会议结束时：

1. 点击「结束会议」按钮
2. 系统会显示确认对话框，包含：
   - 会议名称
   - 会议时长
   - 提示"结束后将保存完整记录"
3. 点击确认，会议记录自动保存

### 6. 查看历史会议

在「会议历史」区域：

- 查看所有已结束的会议列表
- 每个会议显示：名称、时长、参与人数、记录条数、时间
- 点击「查看详情」打开会议详情对话框
- 支持直接导出 TXT 或 MD 格式

## 语音识别说明

### 支持的浏览器

- **Chrome/Edge**：完全支持，自动启动语音识别
- **Firefox/Safari**：不支持 Web Speech API，只能手动输入

### 识别语言

- 默认使用中文识别（`zh-CN`）
- 支持中英文混合识别
- 识别质量取决于网络状况和环境噪音

### 隐私说明

- Web Speech API 会将语音数据发送到 Google 服务器进行处理
- 如果不使用语音识别功能，无需联网
- 所有会议记录仅保存在本地，不会上传到任何服务器

### 常见问题

**Q: 为什么语音识别不准确？**

A: 可能原因：
- 环境噪音过大
- 说话人离麦克风太远
- 网络状况不佳
- 多人同时说话

建议：
- 尽量在安静的环境中使用
- 说话人靠近麦克风
- 确保网络连接稳定
- 一人说完后再让下一人说

**Q: 语音识别突然停止了？**

A: Web Speech API 有时会自动停止。系统会自动尝试重启，如果仍然失败：
- 检查浏览器是否授予麦克风权限
- 检查是否有其他应用占用了麦克风
- 刷新页面后重试

**Q: 可以离线使用吗？**

A: 
- 手动输入模式：完全离线可用
- 语音识别模式：需要联网（Google 服务器处理）

### 导出方式

**从会议列表导出**
1. 在会议历史中找到目标会议
2. 点击「导出 TXT」或「导出 MD」按钮
3. 文件自动下载

**从会议详情导出**
1. 点击「查看详情」打开会议详情
2. 在对话框底部点击「导出 TXT」或「导出 MD」
3. 文件自动下载

**文件名规则**
- 格式：`日期_会议名称.txt` 或 `日期_会议名称.md`
- 示例：`2026-09-17_产品评审会.md`
- 特殊字符会自动替换为下划线

## 数据存储

### 存储位置

所有会议数据存储在浏览器本地：
- 存储键：`coretab_meetings_v1`
- 存储方式：`localStorage`
- 容量限制：约 5MB（可存储数千条会议记录）

### 数据安全

- 数据不会上传到任何服务器
- 卸载扩展会清除所有数据
- 建议定期导出重要会议记录作为备份

### 数据迁移

目前不支持自动云同步，但你可以：
1. 导出会议记录为 TXT/MD 文件
2. 保存到云盘或其他存储服务
3. 需要时手动导入到笔记软件

## 技术细节

### 数据模型

```javascript
{
  id: string,              // 唯一标识（UUID）
  title: string,           // 会议名称
  status: string,          // 状态：'active' | 'ended'
  participants: string[],  // 参与人列表
  transcript: [{           // 转写记录
    speaker: string,       // 说话人
    text: string,          // 转写文本
    timestamp: number      // 相对时间（毫秒）

  summary: string[],       // 摘要条目
  keyPoints: string[],     // 关键结论

  }],
  createdAt: number,       // 创建时间戳
  updatedAt: number,       // 更新时间戳
  duration: number         // 会议时长（毫秒）
}
```

### Web Speech API 集成

```javascript
const SpeechRecognition = window.SpeechRecognition || window.webkitSpeechRecognition;

// 创建识别实例

recognition.lang = 'zh-CN';           // 中文识别
recognition.continuous = true;        // 持续识别
recognition.interimResults = true;    // 中间结果

// 处理识别结果
recognition.onresult = (e) => {
  for (let i = e.resultIndex; i < e.results.length; i++) {
    if (e.results[i].isFinal) {
      const text = e.results[i][0].transcript.trim();
      // 添加到转写列表
    }
  }
};

// 自动重连
recognition.onend = () => {
  if (recognizing && active && !pausedAt) {
    recognition.start();  // 自动重启
  }
};
```

### 暂停/恢复机制

## 最佳实践

### 会议前

1. **测试麦克风**：在会议前测试语音识别是否正常工作
2. **准备环境**：选择安静的环境，减少背景噪音
3. **告知参与者**：让所有参与者知道会议会被录音
4. **准备备用方案**：如果语音识别失败，可以切换到手动输入

### 会议中

1. **一人一说**：避免多人同时说话，提高识别准确率
2. **清晰发音**：说话时尽量清晰、匀速
3. **及时整理**：在会议进行中就添加摘要和行动项
4. **定期保存**：长时间会议可以中途结束并保存，然后开始新会议

### 会议后

1. **补充细节**：回顾会议记录，补充遗漏的信息
2. **整理行动项**：确保每个行动项都有明确的负责人
3. **导出备份**：导出重要会议记录作为备份
4. **分享记录**：将导出的文件分享给未参会的同事

## 故障排除

### 问题：无法启动语音识别

**可能原因**：
- 浏览器不支持 Web Speech API
- 未授予麦克风权限
- 麦克风被其他应用占用

**解决方法**：
1. 使用 Chrome 或 Edge 浏览器
2. 在浏览器设置中允许麦克风权限
3. 关闭其他使用麦克风的应用
4. 刷新页面重试

### 问题：识别结果不准确

**可能原因**：
- 环境噪音过大
- 说话人离麦克风太远
- 网络状况不佳

**解决方法**：
1. 选择安静的环境
2. 靠近麦克风说话
3. 确保网络连接稳定
4. 使用手动输入补充不准确的部分

### 问题：会议数据丢失

**可能原因**：
- 清除了浏览器数据
- 卸载了扩展
- 使用了隐身模式

**解决方法**：
1. 定期导出重要会议记录
2. 不要清除浏览器数据
3. 在正常模式下使用扩展

### 问题：导出文件乱码

**可能原因**：
- 打开文件的编辑器编码设置不正确

**解决方法**：
1. 使用 UTF-8 编码打开文件
2. 推荐使用 VS Code、Sublime Text 等现代编辑器
3. Markdown 文件可以用 Typora、Obsidian 等工具打开
