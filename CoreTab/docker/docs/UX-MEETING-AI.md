# 交互设计：会议实时 AI 分析引擎

> 版本 1.0 — 2026-09-17  
> 基于 PRD-MEETING-AI.md v1.0 和 ARCH-MEETING-AI.md v1.0

---

## 1. 设计原则

### 1.1 核心理念

- **辅助不干扰**：AI 分析是辅助工具，不应成为会议焦点
- **渐进式展示**：从概要到详情，按需展开
- **即时反馈**：分析状态、成本消耗实时可见
- **可控性**：用户可随时暂停、调整、忽略 AI 建议

### 1.2 设计约束

- 保持与现有 Meetings 工作台视觉一致性
- 适配 1280px+ 宽屏，优雅降级到 900px
- 所有交互支持键盘操作
- 符合 Chrome Extension 弹窗尺寸限制

## 2. 整体布局

### 2.1 三列布局结构

```
┌─────────────────────────────────────────────────────────────────────┐
│  [返回] 会议标题                          [ASR设置] [AI设置] [结束] │
├──────────────────────┬──────────────────┬───────────────────────────┤
│   实时转写 (45%)      │   要点总结 (25%)  │    观点分析 (30%)         │
│                      │                  │                           │
│   [说话人] [输入]     │  📋 当前要点      │  🔍 最新观点              │
│   [+]                │  1. Q3延迟2周     │  张明: "两周内做完"       │
│                      │  2. 增加导出      │                           │
│   转写列表...         │  3. 安全性质疑    │  表面: 承诺两周完成       │
│   (可滚动)           │                  │  隐含: 可能低估复杂度     │
│                      │  [上次: 12:34]    │                           │
│                      │                  │  ⚠️ 逻辑漏洞 (2)          │
│                      │                  │  💬 应对话术 (3)          │
│                      │                  │                           │
│                      │                  │  [历史观点 ▼]             │
└──────────────────────┴──────────────────┴───────────────────────────┘
```

### 2.2 响应式断点

| 断点 | 布局 | 说明 |
|------|------|------|
| ≥ 1280px | 三列并排 | 45% / 25% / 30% |
| 900-1279px | 两列 + 折叠 | 转写 60% + 右侧 Tab 切换（要点/观点） |
| < 900px | 单列堆叠 | 转写 → 要点 → 观点（可折叠） |

### 2.3 列宽比例说明

- **转写列 (45%)**：主信息源，需要最大空间展示完整对话
- **要点列 (25%)**：概览性质，精炼展示
- **观点列 (30%)**：详情展示，需要足够空间展开分析

### 3.3 交互细节

#### 3.3.1 服务商选择

- 点击卡片选中，选中状态有绿色边框
- 切换服务商时，自动更新 API Key 占位符和帮助链接
- 如果已保存过该服务商的 Key，自动填充

#### 3.3.2 API Key 输入

- 密码类型输入框，默认隐藏
- 右侧有「显示/隐藏」切换按钮
- 失焦时自动验证格式（DeepSeek: sk-开头）
- 验证失败显示红色提示

#### 3.3.3 测试连接

- 点击后按钮变为加载状态
- 发送简单测试请求（"你好"）
- 成功：显示绿色提示「连接成功」
- 失败：显示红色提示，附带错误原因

#### 3.3.4 参数调整

- 滑块 + 数字输入框双模式
- 滑块拖动时实时更新数字
- 数字输入时实时更新滑块位置
- 超出范围时自动修正

#### 3.3.5 会议类型选择

- 单选按钮组，默认选中「评审会」
- 选中项有绿色背景
- 切换类型会更新系统 Prompt（用户不可见）

### 3.4 状态流转

```
未配置 → 引导配置 → 测试中 → 已配置 → 分析中
   ↑                                    ↓
   └────────── 配置失效 ←──────────────┘
```

| 状态 | UI 表现 |
|------|---------|
| 未配置 | AI 面板显示「配置 AI 分析」引导卡片 |
| 测试中 | 按钮 loading，禁用其他操作 |
| 已配置 | AI 面板正常显示分析结果 |
| 分析中 | 要点/观点面板有「分析中...」指示器 |
| 配置失效 | 顶部显示黄色警告条 |
